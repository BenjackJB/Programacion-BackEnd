Database model:

1. teacher
- id: INT, PRIMARY KEY
- first_name: VARCHAR, required
- last_name: VARCHAR, required

2. student
- id: INT, PRIMARY KEY
- first_name: VARCHAR, required
- last_name: VARCHAR, required

3. course
- id: INT, PRIMARY KEY
- name: VARCHAR, required
- teacher_id: INT, FOREIGN KEY -> teacher.id

Relationship:
- One teacher can teach many courses.
- Each course has exactly one teacher.

4. student_course
- student_id: INT, PRIMARY KEY + FOREIGN KEY -> student.id
- course_id: INT, PRIMARY KEY + FOREIGN KEY -> course.id

Relationship:
- Students and courses have a many-to-many relationship.
- student_course is the junction table.
- Composite primary key: (student_id, course_id).

Summary:
teacher 1:N course
student N:M course through student_course
